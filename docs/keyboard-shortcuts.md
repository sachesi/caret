# Keyboard shortcuts

Ctrl+? shows this list inside the application.

Shortcuts of the window take Ctrl and Shift together, so that Ctrl and a letter reach the
programs in the terminal.

| Keys | |
|---|---|
| Ctrl+Shift+N | New window |
| Ctrl+Shift+T | New tab |
| Ctrl+Shift+W | Close tab |
| Ctrl+Shift+Q | Close window |
| Ctrl+Page Down, Ctrl+Page Up | Next, previous tab |
| Ctrl+Shift+Page Down, Ctrl+Shift+Page Up | Move the tab right, left |
| Alt+1 … Alt+9, Alt+0 | Go to that tab, Alt+0 to the tenth |
| Ctrl+Shift+O | Show all tabs |
| Ctrl+Shift+H | Show or hide the title bar |
| F11 | Full screen |
| Ctrl+Shift+C, Ctrl+Shift+V | Copy, paste |
| Ctrl+Shift+A, Ctrl+Shift+D | Select all text, including the history, and deselect |
| Ctrl+Shift+F | Find in the history |
| Shift+Page Up, Shift+Page Down | Scroll a page |
| Ctrl+Shift+Up, Ctrl+Shift+Down | Scroll to the previous, next prompt, where the shell marks them |
| Ctrl++, Ctrl+-, Ctrl+0 | Zoom in, out, back to the font's size |
| Menu | The context menu, at the cursor |
| Ctrl+, | Preferences |
| Ctrl+? | This list |

In the find bar, Enter finds the next match upwards, and the arrows beside the entry go
either way. Escape closes it.
